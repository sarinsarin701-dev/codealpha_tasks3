# Language Learning App

## 📌 Project Overview

The Language Learning App is an interactive mobile application designed to help users learn a new language through vocabulary, grammar, phrases, flashcards, and quizzes.

The app provides a simple and user-friendly interface for learning new words and practicing language skills.

## ✨ Features

* 📚 Vocabulary learning
* 📝 Grammar practice
* 💬 Common phrases and sentences
* 🔄 Interactive flashcards
* 🔊 Pronunciation support
* 🧠 Practice quizzes
* 📊 Quiz score tracking
* 🎨 Clean and user-friendly interface
* 📱 Mobile-friendly design

## 📂 Categories

### Vocabulary

Users can learn useful everyday vocabulary words with their translations and pronunciations.

### Grammar

Users can practice basic grammar and sentence structures.

### Phrases

Users can learn commonly used phrases and sentences for daily communication.

## 🛠️ Technologies Used

* React Native
* Expo
* JavaScript
* React Hooks
* Expo Snack

## ⚙️ How It Works

1. Open the application.
2. Select the **Learn** section.
3. Choose a category such as Vocabulary, Grammar, or Phrases.
4. View the word or sentence on the flashcard.
5. Tap **Show Translation** to see the meaning and pronunciation.
6. Use Previous and Next buttons to continue learning.
7. Select **Quiz** to practice what you have learned.
8. Complete the quiz and check your score.
